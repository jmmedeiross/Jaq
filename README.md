# Jaq Alongamentos

Aplicação Full Stack de gestão de salão com C#, .NET 10, ASP.NET Core, Entity Framework Core, SQLite e JavaScript.

[![Testes do Jaq](https://github.com/jmmedeiross/Jaq/actions/workflows/ci.yml/badge.svg)](https://github.com/jmmedeiross/Jaq/actions/workflows/ci.yml)

## Código e documentação

O projeto está em [`projects/jaq-alongamentos`](projects/jaq-alongamentos). Leia as [instruções de execução, testes e limites](projects/jaq-alongamentos/README.md).

Inclui agenda por profissional, clientes e fichas técnicas, comandas com vários serviços, recebimentos e comissões, perfis de acesso e proteção contra alterações concorrentes.

O catálogo público contém valores fictícios de demonstração. A versão local funciona; a publicação na internet aguarda validação no servidor. O sistema atende um único salão; assinatura SaaS e isolamento entre salões ainda não foram implementados.
